# 增量数据添加方案

## 一、现有代码分析

项目已经有多个 seed 文件，其中 `seed-membership.ts`、`seed-i18n.ts`、`seed-guardian-spirits.ts` 已经实现了较好的增量逻辑，但 `seed.ts` 仍然是先删除后重建的方式，这会破坏现有数据。

## 二、核心设计原则

1. **不删除现有数据** - 永远不使用 `deleteMany` 或 `drop` 操作
2. **唯一性校验** - 使用 Prisma 的 unique 约束和 `findUnique/findFirst` 检查
3. **事务处理** - 使用 Prisma 事务确保原子性
4. **详细日志** - 记录每个操作的结果
5. **回滚机制** - 利用事务特性自动回滚
6. **版本管理** - 使用种子版本表追踪已执行的种子

## 三、具体实现方法

### 1. 创建种子版本表

在 `schema.prisma` 中添加版本追踪表：

```prisma
model SeedVersion {
  id        String   @id @default(uuid())
  name      String   @unique
  version   Int
  executedAt DateTime @default(now())
  status    String   @default("SUCCESS") // SUCCESS, FAILED, PENDING

  @@map("seed_versions")
}
```

### 2. 创建通用增量种子工具类

创建 `backend/prisma/utils/seed-utils.ts`：

```typescript
import { PrismaClient, Prisma } from '@prisma/client';

const prisma = new PrismaClient();

export interface SeedOperationResult {
  success: boolean;
  created: number;
  updated: number;
  skipped: number;
  errors: string[];
}

export class SeedManager {
  private name: string;
  private version: number;
  private logger: (msg: string) => void;

  constructor(name: string, version: number, logger: (msg: string) => void = console.log) {
    this.name = name;
    this.version = version;
    this.logger = logger;
  }

  async shouldExecute(): Promise<boolean> {
    const existing = await prisma.seedVersion.findUnique({
      where: { name: this.name },
    });

    if (!existing) {
      this.logger(`Seed ${this.name} not executed before, will run version ${this.version}`);
      return true;
    }

    if (existing.version < this.version) {
      this.logger(`Seed ${this.name} has version ${existing.version}, will upgrade to ${this.version}`);
      return true;
    }

    this.logger(`Seed ${this.name} already at version ${this.version}, skipping`);
    return false;
  }

  async markAsExecuted(success: boolean = true, errors: string[] = []): Promise<void> {
    await prisma.seedVersion.upsert({
      where: { name: this.name },
      create: {
        name: this.name,
        version: this.version,
        status: success ? "SUCCESS" : "FAILED",
      },
      update: {
        version: this.version,
        status: success ? "SUCCESS" : "FAILED",
        executedAt: new Date(),
      },
    });
  }

  async safeUpsert<T extends { [key: string]: any }>(
    modelName: keyof PrismaClient,
    uniqueWhere: any,
    data: T,
    upsert: boolean = true
  ): Promise<"created" | "updated" | "skipped"> {
    const model = prisma[modelName] as any;
    const existing = await model.findUnique({ where: uniqueWhere });

    if (!existing) {
      await model.create({ data });
      this.logger(`Created ${modelName}: ${JSON.stringify(uniqueWhere)}`);
      return "created";
    }

    if (upsert) {
      await model.update({
        where: uniqueWhere,
        data: { ...data, updatedAt: new Date() },
      });
      this.logger(`Updated ${modelName}: ${JSON.stringify(uniqueWhere)}`);
      return "updated";
    }

    this.logger(`Skipped ${modelName}: ${JSON.stringify(uniqueWhere)} (already exists)`);
    return "skipped";
  }

  async transaction<T>(
    fn: (tx: Prisma.TransactionClient) => Promise<T>
  ): Promise<T> {
    return await prisma.$transaction(fn);
  }
}
```

### 3. 重构主种子文件为增量模式

修改 `backend/prisma/seed.ts`，移除 `deleteMany` 操作，使用增量逻辑：

```typescript
import { PrismaClient } from '@prisma/client';
import { SeedManager } from './utils/seed-utils';

const prisma = new PrismaClient();

async function main() {
  const seedManager = new SeedManager('main_seed', 2);
  
  if (!(await seedManager.shouldExecute())) {
    return;
  }

  try {
    await seedManager.transaction(async (tx) => {
      console.log('Start incremental seeding...');
      
      let result = { created: 0, updated: 0, skipped: 0 };

      // Stories - 使用 id 作为唯一标识
      const stories = [
        {
          id: 'story_1',
          title: '勇敢的小兔子',
          coverUrl: 'http://192.168.124.13:3000/api/v1/images/logo.png',
          audioUrl: 'http://192.168.124.13:3000/api/v1/audio/raining-S00-00-01.m4a',
          duration: 180,
          category: 'brave',
          description: '一只小兔子克服恐惧的故事',
          isPremium: false,
        },
      ];

      for (const story of stories) {
        const existing = await tx.story.findUnique({ where: { id: story.id } });
        if (!existing) {
          await tx.story.create({ data: story });
          result.created++;
          console.log(`Created story: ${story.title}`);
        } else {
          result.skipped++;
          console.log(`Skipped story: ${story.title} (already exists)`);
        }
      }

      // Courses
      const courses = [
        {
          id: 'course_1',
          level: 1,
          name: '微光适应训练',
          description: '认识黑暗，了解黑暗不可怕',
          imageUrl: 'http://192.168.124.13:3000/api/v1/images/logo.png',
          totalLessons: 10,
          completedLessons: 3,
          isUnlocked: true,
          estimatedDuration: '7天',
          difficulty: 'easy',
          isPremium: false,
        },
      ];

      for (const course of courses) {
        const existing = await tx.course.findUnique({ where: { id: course.id } });
        if (!existing) {
          await tx.course.create({ data: course });
          result.created++;
          console.log(`Created course: ${course.name}`);
        } else {
          result.skipped++;
          console.log(`Skipped course: ${course.name} (already exists)`);
        }
      }

      console.log(`Incremental seeding completed: ${result.created} created, ${result.updated} updated, ${result.skipped} skipped`);
    });

    await seedManager.markAsExecuted(true);
  } catch (e) {
    console.error('Seeding failed:', e);
    await seedManager.markAsExecuted(false, [String(e)]);
    throw e;
  }
}

main()
  .catch((e) => {
    console.error(e);
    process.exit(1);
  })
  .finally(async () => {
    await prisma.$disconnect();
  });
```

### 6. 单元测试示例

import { PrismaClient } from '@prisma/client';
import { SeedManager } from './utils/seed-utils';

const prisma = new PrismaClient();

describe('Seed Tests', () => {
  beforeAll(async () => {
    // 可以在这里设置测试数据库
  });

  afterAll(async () => {
    await prisma.$disconnect();
  });

  test('SeedManager should track versions correctly', async () => {
    const manager = new SeedManager('test_seed', 1);
    const shouldExecute = await manager.shouldExecute();
    expect(shouldExecute).toBe(true);
    
    await manager.markAsExecuted(true);
    
    const shouldExecuteAgain = await manager.shouldExecute();
    expect(shouldExecuteAgain).toBe(false);
  });

  test('Incremental seed should not overwrite existing data', async () => {
    // 创建测试数据
    const testStory = {
      id: 'test_story_1',
      title: 'Test Story',
      coverUrl: 'test.jpg',
      audioUrl: 'test.mp3',
      duration: 100,
      category: 'test',
      isPremium: false,
    };

    await prisma.story.create({ data: testStory });

    // 尝试再次插入相同数据
    const existing = await prisma.story.findUnique({ where: { id: testStory.id } });
    expect(existing).not.toBeNull();

    // 清理测试数据
    await prisma.story.delete({ where: { id: testStory.id } });
  });

  test('Transaction should rollback on error', async () => {
    const manager = new SeedManager('test_transaction', 1);
    
    try {
      await manager.transaction(async (tx) => {
        // 创建一个记录
        await tx.story.create({
          data: {
            id: 'rollback_test_1',
            title: 'Rollback Test',
            coverUrl: 'test.jpg',
            audioUrl: 'test.mp3',
            duration: 100,
            category: 'test',
            isPremium: false,
          },
        });
        
        // 抛出错误触发回滚
        throw new Error('Test rollback');
      });
    } catch (e) {
      // 期望错误
    }

    // 验证记录不存在
    const record = await prisma.story.findUnique({ where: { id: 'rollback_test_1' } });
    expect(record).toBeNull();
  });
});

## 四、关键安全措施总结

| 安全措施 | 实现方式 |
|---------|---------|
| **防止数据删除** | 移除所有 `deleteMany` 操作 |
| **唯一性校验** | 使用 `findUnique` + 事务 + 数据库唯一约束 |
| **原子性** | 使用 `prisma.$transaction()` |
| **版本追踪** | `SeedVersion` 表 + `SeedManager` 类 |
| **日志记录** | 详细的控制台日志 + 执行状态记录 |
| **错误回滚** | 事务自动回滚 + 失败状态标记 |
| **幂等性** | 种子可以多次安全执行，不会重复创建 |

## 五、执行流程

1. **首次执行**：运行 `npm run db:seed:main` 初始化基础数据
2. **添加新数据**：修改 `seed-incremental.ts` 中的数据，更新版本号，运行 `npm run db:seed:incremental`
3. **安全检查**：每次执行前会检查版本，已执行过的种子会自动跳过
4. **错误处理**：如果出错，事务自动回滚，版本状态标记为 FAILED

这个方案确保了数据的安全性和完整性，同时提供了灵活的增量数据添加能力。
