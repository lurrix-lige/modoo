# Dozoo 项目完整实施计划文档

## 1. 需求分析与功能拆解

### 1.1 项目概述

**项目名称**: Dozoo（梦兜）- 儿童睡前陪伴应用\
**目标用户**: 儿童（2-8岁）及其家长\
**核心价值**: 通过故事、呼吸练习、课程等内容，帮助儿童建立良好的睡眠习惯，缓解睡前焦虑和恐惧。

### 1.2 功能模块拆解

| 模块       | 子功能            | 说明          | 优先级 |
| -------- | -------------- | ----------- | --- |
| **欢迎引导** | 欢迎页、引导页、语言选择   | 首次用户引导体验    | P0  |
| **用户认证** | 手机号登录、验证码、注册   | 用户身份验证与注册   | P0  |
| **儿童首页** | 守护精灵、故事列表、快捷入口 | 儿童主界面       | P0  |
| **故事播放** | 音频播放、进度控制、收藏   | 故事音频播放器     | P0  |
| **脱敏课程** | 课程列表、课时详情、学习进度 | 循序渐进的脱敏训练   | P0  |
| **呼吸练习** | 呼吸动画、白噪音、舒适模式  | 放松身心助眠      | P0  |
| **睡眠打卡** | 打卡记录、睡眠统计、连续打卡 | 养成睡眠好习惯     | P1  |
| **家长首页** | 睡眠报告、数据趋势、推荐内容 | 家长查看儿童睡眠数据  | P0  |
| **育儿知识** | 文章列表、文章详情、收藏搜索 | 提供育儿知识      | P1  |
| **话术库**  | 场景分类、话术搜索、收藏   | 家长应对儿童情绪的话术 | P1  |
| **专家咨询** | 专家列表、预约时间、预约管理 | 专业心理咨询服务    | P2  |
| **会员系统** | 套餐展示、支付购买、权益管理 | 会员订阅服务      | P1  |
| **设置中心** | 主题切换、语言切换、通知设置 | 个性化配置       | P2  |

### 1.3 用户角色与权限

| 角色        | 权限                  | 进入方式     |
| --------- | ------------------- | -------- |
| **游客**    | 浏览欢迎页、查看免费内容、试听故事   | 首次打开APP  |
| **普通用户**  | 完整功能访问（不含VIP内容）     | 手机号登录    |
| **VIP会员** | 全部功能（含专属内容）         | 购买会员套餐   |
| **儿童模式**  | 简化界面、受限功能（故事/课程/呼吸） | 家长切换进入   |
| **家长模式**  | 完整管理功能（数据/设置/咨询）    | 儿童锁验证后进入 |

## 2. 数据模型与接口规范设计

### 2.1 核心数据模型

#### 用户相关

- `UserProfile`: 用户档案
- `ChildProfile`: 儿童档案

#### 内容相关

- `Story`: 故事
- `Course`: 课程
- `Lesson`: 课时
- `BreathingExercise`: 呼吸练习
-  WhiteNoise：白噪声
- `KnowledgeArticle`: 知识文章
- `Dialogue`: 话术
- `ExpertProfile`: 专家
- `ConsultationBooking`: 预约

#### 睡眠数据相关

- `CheckInRecord`: 打卡记录
- `SleepStatistics`: 睡眠统计
- `DailySleepData`: 日睡眠数据
- `MonthlySleepData`: 月睡眠数据

#### 会员相关

- `MembershipPlanDetail`: 会员套餐

### 2.2 API 接口规范

#### 认证接口

| API 路径               | HTTP方法 | 功能      | 认证要求         |
| -------------------- | ------ | ------- | ------------ |
| `/api/auth/sendCode` | POST   | 发送验证码   | 无            |
| `/api/auth/login`    | POST   | 用户登录    | 无            |
| `/api/auth/register` | POST   | 用户注册    | 无            |
| `/api/auth/refresh`  | POST   | 刷新Token | RefreshToken |
| `/api/auth/logout`   | POST   | 退出登录    | AccessToken  |

#### 内容接口

| API 路径             | HTTP方法 | 功能       | 认证要求 |
| ------------------ | ------ | -------- | ---- |
| `/api/stories`     | GET    | 获取故事列表   | 无    |
| `/api/stories/:id` | GET    | 获取故事详情   | 无    |
| `/api/courses`     | GET    | 获取课程列表   | 无    |
| `/api/courses/:id` | GET    | 获取课程详情   | 无    |
| `/api/breathing`   | GET    | 获取呼吸练习   | 无    |
| `/api/articles`    | GET    | 获取知识文章列表 | 无    |
| `/api/dialogues`   | GET    | 获取话术列表   | 无    |

#### 睡眠数据接口

| API 路径                  | HTTP方法 | 功能       | 认证要求        |
| ----------------------- | ------ | -------- | ----------- |
| `/api/checkin`          | POST   | 添加打卡记录   | AccessToken |
| `/api/checkin`          | GET    | 获取打卡记录列表 | AccessToken |
| `/api/sleep/statistics` | GET    | 获取睡眠统计数据 | AccessToken |

## 3. 前后端技术栈与实现方案

### 3.1 前端技术栈

| 分类   | 技术                  | 说明      |
| ---- | ------------------- | ------- |
| 框架   | React Native + Expo | 跨平台移动应用 |
| 状态管理 | Zustand             | 轻量级状态管理 |
| 导航   | React Navigation    | 路由导航    |
| 国际化  | i18next             | 多语言支持   |
| 音频   | expo-av             | 音频播放    |
| 存储   | AsyncStorage        | 本地存储    |
| 类型   | TypeScript          | 类型安全    |

### 3.2 后端技术栈（建议）

| 分类                  | 技术                   | 说明     |
| ------------------- | -------------------- | ------ |
| 语言                  | Node.js / TypeScript | 服务端开发  |
| 框架（使用backned已建成的实现） | NestJS               | 企业级框架  |
| 数据库                 | Sqlite               | 关系型数据库 |
| ORM                 | Prisma               | 数据库访问  |
| 缓存（暂时不考虑）           | Redis                | 数据缓存   |

### 3.3 架构设计

#### 前端架构

```
Presentation Layer (Screens/Components)
      ↓
Business Layer (Store/Services)
      ↓
Data Layer (Mock Data/API Client)
```

## 6. 测试计划与验收标准

### 6.1 测试策略

| 测试类型     | 覆盖范围       | 工具             |
| -------- | ---------- | -------------- |
| **单元测试** | 工具函数、服务类   | Jest           |
| **集成测试** | API调用、数据流转 | Jest + Mock    |
| **UI测试** | 页面渲染、交互    | Detox          |
| **性能测试** | 加载时间、内存占用  | React DevTools |

### 6.2 验收标准

#### 功能验收

- 用户认证：登录/注册成功
- 故事播放：音频正常播放，进度正确
- 课程学习：进度正确更新
- 呼吸练习：动画正确显示
- 睡眠打卡：记录正确保存

#### 非功能验收

- 启动时间：< 2秒
- 页面切换：< 500ms
- 音频加载：< 3秒
- 内存占用：< 200MB
- 稳定性：7天无崩溃
