## 1. 守护IP故事播放模块

### 1.1 核心功能描述与设计理念

**核心功能：**
- 守护IP角色展示与互动（月亮精灵/萤火虫卫士）
- 故事列表展示与分类筛选
- 音频故事播放控制
- 故事进度记录与断点续播

**设计理念：**
- 基于儿童心理学泛灵论，让孩子相信守护IP是真实存在的朋友
- 通过温暖的视觉设计和柔和的色彩营造安全感

### 3.3 技术实现方案

**呼吸动画核心代码：**
```javascript
const [breathPhase, setBreathPhase] = useState('inhale');
const [balloonScale, setBalloonScale] = useState(1);

useEffect(() => {
  const phases = ['inhale', 'hold', 'exhale', 'hold'];
  let currentIndex = 0;
  
  const interval = setInterval(() => {
    currentIndex = (currentIndex + 1) % 4;
    setBreathPhase(phases[currentIndex]);
    
    // 吸气时放大，呼气时缩小
    if (phases[currentIndex] === 'inhale') {
      setBalloonScale(prev => Math.min(prev + 0.15, 1.5));
    } else if (phases[currentIndex] === 'exhale') {
      setBalloonScale(prev => Math.max(prev - 0.15, 0.8));
    }
  }, 1000);
  
  return () => clearInterval(interval);
}, []);
```

### 7.2 技术实现方案

**音频播放服务：**
```javascript
// AudioService.js
import TrackPlayer from 'react-native-track-player';

export const AudioService = {
  async init() {
    await TrackPlayer.setupPlayer({
      maxCacheSize: 1024 * 1024 * 50, // 50MB缓存
    });
    
    await TrackPlayer.updateOptions({
      stopWithApp: false,
      capabilities: [
        TrackPlayer.CAPABILITY_PLAY,
        TrackPlayer.CAPABILITY_PAUSE,
        TrackPlayer.CAPABILITY_STOP,
        TrackPlayer.CAPABILITY_SKIP_TO_NEXT,
        TrackPlayer.CAPABILITY_SKIP_TO_PREVIOUS,
        TrackPlayer.CAPABILITY_SEEK_TO,
      ],
      compactCapabilities: [
        TrackPlayer.CAPABILITY_PLAY,
        TrackPlayer.CAPABILITY_PAUSE,
      ],
    });
  },
  
  async play(track) {
    await TrackPlayer.reset();
    await TrackPlayer.add(track);
    await TrackPlayer.play();
  },
  
  async pause() {
    await TrackPlayer.pause();
  },
  
  async stop() {
    await TrackPlayer.stop();
    await TrackPlayer.reset();
  },
};
```
