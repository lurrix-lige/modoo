# 小米提示词

年轻妈妈  偏低沉、柔软、气声偏多、语速慢、音调平缓不起伏的温柔治愈音。
1. 最佳音色特质
音调：中低音、不要尖细高亢，越低沉温柔越安神
质感：软糯、带轻微气声、气息轻，不明亮、不清脆
语速：慢、拖音柔和，一字一句轻轻落
情绪：无起伏、不兴奋、不欢快，平静舒缓
音量：耳语级、偏低音量，像耳边轻声呢喃
